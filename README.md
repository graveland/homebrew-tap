# graveland tap

Homebrew casks for graveland's tools.

## rafiki

Agent daemon, proxy and cockpit.

```sh
brew install graveland/tap/rafiki
```

Then run `rafiki setup` to finish installing — it needs Docker (or OrbStack) and a
Claude login; API keys are optional.

The cask in `Casks/` is generated by GoReleaser on each `v*` tag of
[graveland/rafiki](https://github.com/graveland/rafiki); do not hand-edit it.
